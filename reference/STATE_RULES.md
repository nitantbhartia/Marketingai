# State-Specific Insurance Rules

This file contains factual, verifiable information about auto insurance total loss regulations by state.
Used by the State Regulation Validator to ensure content accuracy.

## California

- **Threshold Method**: TLF (Total Loss Formula)
- **Threshold Value**: None (no percentage — uses formula)
- **Invalid Claims**: "75%", "80%", "70%" are all incorrect
- **Sales Tax Required**: Yes
- **Reopener Period**: 35 days
- **Diminished Value - First Party**: No
- **Diminished Value - Third Party**: Yes
- **Statute of Limitations**: 3 years
- **Fault System**: At-fault
- **Key Statute**: Cal. Code Regs. § 2695.8

## Texas

- **Threshold Method**: TLT (Total Loss Threshold)
- **Threshold Value**: 100%
- **Sales Tax Required**: Policy-dependent
- **Reopener Period**: None
- **Diminished Value - First Party**: No
- **Diminished Value - Third Party**: Yes
- **Statute of Limitations**: 2 years
- **Fault System**: At-fault
- **Key Statute**: Tex. Ins. Code § 1952.301

## Florida

- **Threshold Method**: TLT (Total Loss Threshold)
- **Threshold Value**: 80%
- **Invalid Claims**: "75%", "70%" are incorrect
- **Sales Tax Required**: Yes
- **Reopener Period**: None
- **Diminished Value - First Party**: No
- **Diminished Value - Third Party**: Yes
- **Statute of Limitations**: 4 years
- **Fault System**: No-fault (for BI); at-fault for property damage
- **Key Statute**: Fla. Stat. § 319.30

## Georgia

- **Threshold Method**: TLF (Total Loss Formula)
- **Threshold Value**: None
- **Sales Tax Required**: Yes
- **Reopener Period**: None
- **Diminished Value - First Party**: Yes ⚠️ **UNIQUE — only state**
- **Diminished Value - Third Party**: Yes
- **Statute of Limitations**: 4 years
- **Fault System**: At-fault
- **Key Statute**: O.C.G.A. § 33-34-6
- **Special Rules**:
  - 2+ major component replacements = total loss
  - 17c formula for DV

## Illinois

- **Threshold Method**: TLF (Total Loss Formula)
- **Threshold Value**: None
- **Sales Tax Required**: Yes
- **Sales Tax Condition**: Must purchase replacement within 30 days
- **Reopener Period**: None
- **Diminished Value - First Party**: No
- **Diminished Value - Third Party**: Yes
- **Statute of Limitations**: 5 years
- **Fault System**: At-fault
- **Key Statute**: 215 ILCS 5/155.22a
- **Special Rules**:
  - Flood vehicles totaled at 50% ACV
  - 30-day purchase window for sales tax

## Ohio

- **Threshold Method**: TLF (Total Loss Formula)
- **Threshold Value**: None
- **Sales Tax Required**: Yes
- **Sales Tax Condition**: Must provide purchase documentation within 30 days
- **Reopener Period**: None
- **Diminished Value - First Party**: No
- **Diminished Value - Third Party**: Yes
- **Statute of Limitations**: 4 years
- **Fault System**: At-fault
- **Key Statute**: Ohio Admin. Code § 3901-1-54
- **Special Rules**:
  - Sales tax capped at claim amount, not replacement vehicle price

## Michigan

- **Threshold Method**: TLT (Total Loss Threshold)
- **Threshold Value**: 75%
- **Sales Tax Required**: Yes
- **Reopener Period**: None
- **Diminished Value - First Party**: No
- **Diminished Value - Third Party**: No ⚠️ **Effectively blocked by mini-tort**
- **Mini-Tort Limit**: $3,000
- **Statute of Limitations**: 3 years
- **Fault System**: No-fault
- **Key Statute**: Mich. Comp. Laws § 257.217c
- **Special Rules**:
  - Mini-tort $3,000 cap on property damage claims
  - DV essentially unavailable
